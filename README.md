# CubicMap

在地图上框选一块**黄金分割比例（1 : 1.618）**的矩形区域，一键生成带边框的路网线稿，并可导出 **5 mm 厚、10 cm 宽**的 3D 打印模型（STL）。

纯静态网站，无需后端：直接打开 `index.html`（需通过 HTTP 服务访问，例如 `npx serve .` 或 `python3 -m http.server`），或部署到 GitHub Pages。

## 使用

1. 搜索地点，或拖动 / 缩放地图，把目标区域放进选框。选框可切换横向 / 纵向，并调整大小，宽高比固定为黄金比例。
2. 点 **生成**：从 OpenStreetMap（Overpass API）获取选区内的道路，生成黑色边框的二维路网图（100 mm 宽画布）。
   - 道路密度默认 **自动**：按道路等级（高速 → 主干 → 次干 → 支路 → 街道 → 服务道路 → 步行道）逐级加入，直到线条覆盖率接近目标值，路多的区域只显示主要道路，路少的区域显示更多细节。也可手动选择显示到哪一级。
   - 可调整线宽、边框颜色 / 宽度、道路颜色、背景色；可下载 SVG / PNG。
3. 点 **Create 3D**：生成三维模型，俯视图即二维图。默认宽 100 mm、总厚 5 mm（2 mm 底板 + 凸起的边框和道路），可修改后下载 STL。
   - 底板厚度设为 0 时得到镂空路网。
   - 为了能打印，三维模型中的线宽不小于“最细线宽”（默认 0.6 mm）。
